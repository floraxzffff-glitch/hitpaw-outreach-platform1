# HitPaw Outreach Platform

Cloud version of the outreach workflow.

## Structure

- `backend/`: FastAPI service for jobs, file uploads, parsing, and future email/search tasks.
- `frontend/`: Vite React dashboard for non-technical users.
- `docs/`: deployment and operation notes.

## Deployment Target

- Frontend: Vercel
- Backend: Render
- Source control: GitHub

## Current V1 Scope

- Backend health check
- Frontend dashboard shell
- Excel upload endpoint
- Environment variable checklist

The existing local scripts will be migrated into API-backed jobs step by step.
