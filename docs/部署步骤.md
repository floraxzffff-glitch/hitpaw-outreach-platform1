# 部署步骤

## 1. 推送到 GitHub

把整个 `hitpaw-outreach-platform1` 文件夹上传到 GitHub 仓库：

`https://github.com/floraxzffff-glitch/hitpaw-outreach-platform1`

## 2. Render 部署后端

1. 打开 Render。
2. New -> Web Service。
3. 连接 GitHub 仓库。
4. Root Directory 填 `backend`。
5. Build Command 填 `pip install -r requirements.txt`。
6. Start Command 填：

```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

7. 添加环境变量。

必填或后续会用到：

- `YOUTUBE_API_KEY`
- `SERPER_API_KEY` 或 `SERPAPI_KEY`
- `OPENAI_API_KEY`
- `SMTP_SERVER`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASSWORD`
- `CORS_ORIGINS`

## 3. Vercel 部署前端

1. 打开 Vercel。
2. Add New Project。
3. 选择同一个 GitHub 仓库。
4. Root Directory 选择 `frontend`。
5. 添加环境变量：

- `VITE_API_BASE`：填写 Render 后端网址，比如 `https://xxx.onrender.com`

## 4. 验证

1. 打开 Vercel 网站。
2. 点“检查后端”。
3. 如果显示“后端正常”，说明前后端部署已打通。
