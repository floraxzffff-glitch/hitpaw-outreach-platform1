# VikPea 外联工作台同事版

## 第一次使用

1. Windows 电脑先双击 `安装依赖_Windows.bat`。
2. 打开 `VikPea_配置.xlsx`，确认发件邮箱、发件人名称、授权码、发送上限。
3. 打开 `VikPea_黑名单.xlsx`，补充不想再联系的人、邮箱或域名。
4. Mac 终端运行：`python3 ~/Downloads/VikPea工作台/VikPea_工作台.py`
5. Windows 双击 `运行工作台.bat`，先选 `1. 交付前自检 / 今日状态`。

## 日常推荐流程

1. 搜索 YouTube KOL 或文章站点。
2. 跑深度找邮箱。
3. 跑邮箱体检。
4. 跑发送首封开发信。
5. 跑读取邮箱回复。
6. 跑自动跟进。
7. 跑关键词复盘。

## 关键词表怎么用

### YouTube 关键词表

文件名必须叫：

`VikPea_搜索关键词.xlsx`

用途：

- 给 `搜索 YouTube KOL` 这一步使用
- 现在脚本**只会跑这张表里你自己填的关键词**
- 不会再自动补额外关键词

建议格式：

| A列 | B列 | C列 |
|---|---|---|
| 关键词 | 启用 | 备注 |

示例：

| 关键词 | 启用 | 备注 |
|---|---|---|
| topaz video ai alternative | 是 | 竞品替代词 |
| ai video upscaler review | 是 | 评测词 |
| capcut video quality tutorial | 否 | 暂停测试 |

使用规则：

- **A列**：填关键词
- **B列**：填 `是` / `否`
- **C列**：可不填，只是给人自己备注看

脚本会跳过这些情况：

- 空白行
- 第一列是表头 `关键词`
- B列写了 `否 / no / 0 / false / 停用 / 禁用`

### 文章关键词表

文件名必须叫：

`VikPea_文章搜索关键词.xlsx`

用途：

- 给 `搜索文章站点` 这一步使用

建议格式和 YouTube 关键词表一样：

| A列 | B列 | C列 |
|---|---|---|
| 关键词 | 启用 | 备注 |

### 填写原则

建议每个人只填自己这轮真正想测的词，不要一口气塞太多。

推荐做法：

1. 一轮先放 10–30 个词
2. 相近词放一起
3. 表现差的词直接在 B 列写 `否`
4. 不要改文件名，不要改 sheet 结构

### 重要提醒

- 关键词表是脚本自动识别的，不需要改代码
- **文件名要固定**
- **关键词放第一列**
- 如果文件名改了、关键词没放第一列，脚本就可能识别不到

## 发送邮件前必须看

发送首封和自动跟进都会生成：

`VikPea_本次发信预览.xlsx`

确认预览无误后，脚本会要求输入 `y / yes / send / SEND` 才会真正发送邮件。

## 常用文件

- `VikPea_工作台.py`：总控菜单。
- `VikPea_交付前自检.py`：检查环境、表格和风险项。
- `VikPea_配置.xlsx`：统一配置。
- `VikPea_黑名单.xlsx`：不联系名单。
- `VikPea_发信名单.xlsx`：待发主表（只放有邮箱、可发送对象）。
- `VikPea_无邮箱候选.xlsx`：无邮箱副表（待深度查邮箱）。
- `VikPea_邮件开发追踪.xlsx`：主追踪表。
- `VikPea_运行日志.txt`：运行记录。

## 如果同事原来就有自己的已联络表

可以直接把她们原来的历史联络表放进同一个文件夹，并改名为：

`VikPea_额外已联络去重.xlsx`

这样运行“发送首封开发信”时，脚本会把这张表也一起当作“已联系过”名单来去重，避免重复联络。

建议旧表里至少保留以下任意几列中的一部分：

- `频道名` / `名称` / `联系人`
- `邮箱`
- `主页链接` / `链接` / `主页/视频链接`

不要求和主追踪表一模一样，但表头尽量写清楚，识别会更稳。

## 注意

- 发信、跟进前关闭 Excel 里打开的相关表格，避免保存失败。
- 不要同时跑两个会写同一个表的脚本。
- 不要直接改 `.py` 代码；优先改配置表、关键词表、黑名单。
- 如果脚本提示缺少依赖，先运行 `安装依赖_Windows.bat`。
