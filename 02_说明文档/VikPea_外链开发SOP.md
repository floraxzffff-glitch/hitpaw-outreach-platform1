# VikPea 外联工作台运行 SOP

版本：V3.0  
更新日期：2026-07-27  
适用范围：VikPea / FotorPea 外联试用与日常执行

## 一、这套 SOP 解决什么问题

这套工作台用于把外联流程拆成固定步骤：

1. 搜目标
2. 查邮箱
3. 体检邮箱
4. 发首封邮件
5. 读回复
6. 跟进
7. 复盘关键词

核心原则只有三条：

- 主发表只放“有邮箱、可发信”的对象
- 没邮箱或邮箱不稳的对象，不直接进主发表
- 所有已联络对象都要进追踪表，避免重复联系

## 二、运行入口

### Mac

终端运行：

```bash
python3 ~/Downloads/VikPea工作台/VikPea_桌面程序.py
```

如果想用命令行工作台，也可以运行：

```bash
python3 ~/Downloads/VikPea工作台/VikPea_工作台.py
```

### Windows

在试用包里双击：

- `一键安装并启动_Windows.bat`：第一次使用
- `运行工作台.bat`：后续直接运行

## 三、第一次使用前要做什么

### 1. 填配置表

先打开：

- `VikPea_配置.xlsx`：通用配置
- `VikPea_配置_VKP.xlsx`：VikPea 邮件模板配置
- `VikPea_配置_FP.xlsx`：FotorPea 邮件模板配置

至少要确认这些内容：

- 发件邮箱
- 发件授权码 / 应用密码
- SMTP / IMAP
- 每日发送上限
- YouTube API Key

### 2. 填关键词表

YouTube 用：

- `VikPea_搜索关键词.xlsx`

文章站点用：

- `VikPea_文章搜索关键词.xlsx`

第二列现在是：

- `是否启用`

填写规则：

- `是` = 启用
- `否` = 不启用

如果全部是 `否`，脚本会直接停止，不会偷偷用内置关键词。

### 3. 放历史去重表

如果同事原来就有自己的已联络名单，放到工作台目录里，并统一命名为：

- `VikPea_额外已联络去重.xlsx`

这张表会参与去重，避免重复联络。

## 四、关键表格分别干什么

### 主流程表

- `VikPea_发信名单.xlsx`
  - 主待发表
  - 只放有邮箱、可发送对象

- `VikPea_邮件开发追踪.xlsx`
  - 总追踪表
  - 已发送、已回复、待跟进都在这里统计

- `VikPea_本次发信预览.xlsx`
  - 每次发信前预览
  - 必看，不看不要发

### 邮箱相关表

- `VikPea_无邮箱候选.xlsx`
  - 搜到了频道，但当前没有稳定邮箱
  - 等待深度找邮箱或人工补充

- `VikPea_待确认邮箱.xlsx`
  - 深度找邮箱命中的“中低置信度邮箱”
  - 不自动发，先人工确认

- `VikPea_人工补充邮箱.xlsx`
  - 人工自己找到邮箱时填这里
  - 后续可转入主发表

### 配置与限制表

- `VikPea_黑名单.xlsx`
  - 不再联系的人 / 邮箱 / 域名

- `VikPea_关键词效果复盘.xlsx`
  - 关键词效果统计

## 五、最新标准流程

### 步骤 1：交付前自检 / 今日状态

先运行：

- `交付前自检 / 今日状态`

用途：

- 检查配置是否缺失
- 检查关键表格是否存在
- 检查追踪表、主发表、无邮箱池是否正常

通过后再开始后面步骤。

### 步骤 2：搜索 YouTube KOL

运行：

- `搜索 YouTube KOL`

脚本现在会优先使用：

- 关键词表中“是否启用 = 是”的词
- YouTube API 拉搜索结果、播放量、频道最新发布时间

当前主筛选逻辑：

- 每个关键词抓一批频道候选
- 命中视频播放量达到最低门槛
- 最近 5 条常规视频平均播放量达到门槛
- 最近 30 天内有常规视频更新
- 去重：已联络、主发表、无邮箱候选、额外去重表

默认配置里常见含义：

- `YOUTUBE_RESULTS_PER_KEYWORD = 80`
  - 每个关键词最多取多少个候选
- `YOUTUBE_MIN_VIDEO_VIEWS = 800`
  - 命中视频最低播放量
- `YOUTUBE_MIN_RECENT_AVG_VIEWS = 1000`
  - 最近 5 条视频平均播放量最低值
- `YOUTUBE_RECENT_VIDEO_COUNT = 5`
  - 取最近几条视频做平均
- `YOUTUBE_ACTIVE_WITHIN_DAYS = 30`
  - 最近多少天内要更新过

输出结果：

- 有稳定邮箱：进 `VikPea_发信名单.xlsx`
- 没邮箱：进 `VikPea_无邮箱候选.xlsx`

注意：

- 现在链接应尽量统一保存为频道主页链接，不再优先保留单条视频链接
- Shorts 不作为“30 天内更新”的判断主体

### 步骤 3：搜索文章站点

运行：

- `搜索文章站点`

用途：

- 用文章关键词找外链站点
- 找到可联系邮箱的网站进入主发表
- 无公开邮箱的网站进入无邮箱池或保留人工判断

当前建议：

- 文章线作为补充
- 不要只盯搜索引擎结果页本身
- 重点看独立站、教程站、评测站、工具导航站

### 步骤 4：深度找邮箱

运行：

- `深度找邮箱`

处理对象：

- `VikPea_无邮箱候选.xlsx`

当前找邮箱顺序是：

1. 看视频描述 / 频道相关公开文本里有没有邮箱
2. 看频道主页 About / 简介里有没有邮箱
3. 看外链落地页、contact、about、media kit 等页面有没有邮箱
4. 再做搜索补查

现在不会把所有命中的邮箱都直接塞进主发表，而是分成三档：

- A 档：高置信度
  - 自动转入主发表
- B 档：中置信度
  - 进入 `VikPea_待确认邮箱.xlsx`
- C 档：低置信度
  - 进入 `VikPea_待确认邮箱.xlsx`

这样可以避免这些问题直接污染主发表：

- 邮箱和频道对不上
- 抓到大公司通用邮箱
- 抓到搜索引擎假结果
- 抓到别的网站、别的平台邮箱

### 步骤 5：人工补充邮箱

如果人工自己找到了邮箱，不要改代码，直接填：

- `VikPea_人工补充邮箱.xlsx`

建议至少填：

- 频道名
- 邮箱
- 主页链接
- 备注

补充后的邮箱后续可以进入发信主流程。

如果你希望直接在无邮箱表里补，也可以补，但规范做法还是优先放人工补充表，方便区分机器结果和人工结果。

### 步骤 6：邮箱体检

运行：

- `邮箱体检`

用途：

- 清理明显异常邮箱
- 过滤不适合直接发送的邮箱
- 帮主发表更干净

### 步骤 7：发送首封开发信

运行：

- `发送首封开发信`

现在的逻辑是：

- 开头可以定制
- 正文主体可以直接读取配置表里的完整模板
- 不再强制所有人都用同一套正文

也就是说，不同同事 / 不同产品线可以各用各的模板：

- VikPea 用 `VikPea_配置_VKP.xlsx`
- FotorPea 用 `VikPea_配置_FP.xlsx`

发送前脚本会先生成：

- `VikPea_本次发信预览.xlsx`

必须先看预览，再确认发送。

### 步骤 8：读取邮箱回复

运行：

- `读取邮箱回复`

用途：

- 把收到的回复回写到追踪表
- 更新状态

### 步骤 9：自动跟进

运行：

- `自动跟进`

用途：

- 按配置好的间隔继续跟进未回复对象

当前建议间隔以 5 天或 7 天为主，不建议太密。

### 步骤 10：关键词复盘

运行：

- `关键词复盘`

用途：

- 看哪些关键词带来了可联络对象
- 看哪些词结果差、浪费搜索配额
- 后续把差词停用，把好词保留

## 六、同事最常改的内容在哪里

### 1. 改搜索词

改：

- `VikPea_搜索关键词.xlsx`
- `VikPea_文章搜索关键词.xlsx`

### 2. 改产品邮件模板

改：

- `VikPea_配置_VKP.xlsx`
- `VikPea_配置_FP.xlsx`

### 3. 改筛选门槛

改：

- `VikPea_配置.xlsx`

常改项包括：

- 每词抓取数量
- 最低播放量
- 最近 5 条平均播放量
- 活跃天数
- 单次发送上限

### 4. 补自己的已联络名单

放：

- `VikPea_额外已联络去重.xlsx`

## 七、现在最重要的几条操作纪律

1. 不要同时运行两个会写同一张表的脚本  
2. 发信前一定看预览表  
3. `待确认邮箱.xlsx` 里的邮箱，不要直接批量发  
4. 关键词第二列只写 `是 / 否`  
5. 关闭正在打开的 Excel / WPS 文件再运行脚本  
6. 历史去重表一定放进工作目录  
7. 人工补充邮箱优先放 `VikPea_人工补充邮箱.xlsx`

## 八、试用时最推荐的最短路径

如果是同事第一次试用，直接按这个顺序来：

1. 打开工作台  
2. 运行 `交付前自检 / 今日状态`  
3. 填好关键词表，把不用的词设成 `否`  
4. 运行 `搜索 YouTube KOL`  
5. 运行 `深度找邮箱`  
6. 打开 `VikPea_待确认邮箱.xlsx` 和 `VikPea_人工补充邮箱.xlsx` 看邮箱  
7. 运行 `邮箱体检`  
8. 运行 `发送首封开发信`  
9. 先看 `VikPea_本次发信预览.xlsx`  
10. 确认无误后再发送

## 九、一句话总结

现在最新版流程不是“搜到就发”，而是：

搜目标 -> 分流邮箱 -> 人工确认可疑邮箱 -> 体检 -> 预览 -> 发信 -> 追踪

这版比之前更稳，尤其是“深度找邮箱”这一段，已经从直接入主表改成了高低置信度分流。
